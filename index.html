Signature Verification Flow

WytNet signs every webhook payload using HMAC-SHA256 to ensure authenticity. The signature is sent in the header X-WhiteNet-Signature.

Python Verification Example 
import hmac
import hashlib
import json

# payload_bytes: Raw HTTP request body bytes
# client_secret: Your App Client Secret
# received_signature: Value of X-WhiteNet-Signature header

# 1. Parse and sort JSON keys to recreate original payload string
payload_dict = json.loads(payload_bytes.decode('utf-8'))
payload_str = json.dumps(payload_dict, sort_keys=True)

# 2. Compute expected signature
expected_signature = hmac.new(
    client_secret.encode('utf-8'),
    payload_str.encode('utf-8'),
    hashlib.sha256
).hexdigest()

# 3. Securely compare signatures
is_valid = hmac.compare_digest(expected_signature, received_signature)

Usage Guidelines & Security Rules

Essential implementation rules for SSO token security and payment webhook durability.

Do's

  • Store your Client Secret securely in your server's system environment variables.
  • Always check and verify the X-WhiteNet-Signature header on incoming payment webhooks to prevent spoofing.
  • Add all domain origins where checkouts can originate to the "Allowed Domains" list.
  • Log and monitor callback responses and webhook HTTP status codes in your developer dashboard.

Don'ts

  • Do not expose the Client Secret in frontend SPA React/Vue/Vite client-side code.
  • Do not bypass webhook signature validation checks in your production environment.
  • Do not use wildcard matches like * in redirect callback URLs in production.
  • Do not configure webhooks to retry infinitely on connection failure; process events asynchronously.
